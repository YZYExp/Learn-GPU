# 系统篇精确教学配图

生成命令：`python3 scripts/figures-systems.py`。使用 Pillow 与工程中的 `assets/fonts/NotoSansCJKsc-Regular.otf`；可用 `--font` 指定其他中文字体。各图宽1600像素、高1200—1400像素；正文标签不小于30像素。脚本只重建本清单9张配图及内部接触表。

配色：米白 `#fbf8f2`、藏蓝 `#12384a`、青 `#167a85`、橙 `#cb7228`。这些图为程序绘制的精确机制/关系示意，与主编提供的模型生成情境图互补；没有使用生图替代可验证的数值与流程。

| 文件 | 教学意义 | 假设、范围与核对点 |
|---|---|---|
| `assets/images/fig-24.png` | 自定义算子需要同时满足前向、反向、元信息、存储行为和系统接口契约 | SiLU实数逐元素公式；反向为上游梯度乘以 `s+x*s*(1-s)`；具体实现类型/设备范围以第24章为准。opcheck与gradcheck职责不同。 |
| `assets/images/fig-25.png` | Roofline将算术强度与计算/带宽上限联系起来 | 双对数坐标；假设匹配运算类型的峰值20 TFLOP/s、带宽1 TB/s；FP32向量加法每元素12字节、1 FLOP，强度1/12，带宽上限83.3 GFLOP/s。仅数学模型，没有产品跑分。 |
| `assets/images/fig-26.png` | 搬运和计算不同分块时可以重叠，但有填充与排空 | 四块、搬运3单位、计算5单位；串行32，双缓冲理想23。搬运起点0/3/8/13，计算起点3/8/13/18；槽位复用在前一读操作完成后，无资源争用与同步开销假设。 |
| `assets/images/fig-28.png` | 现代DSL的主要差别是表达层级与控制边界 | 六条工具路线，不是性能排行榜。CuTe DSL与cuTile不是同一项目。支持与后端需按版本核对，未承诺跨平台等速。 |
| `assets/images/fig-30.png` | DDP完整复制与全分片参数常驻状态的区别 | 四卡四片参数；仅展示同一参数张量，不把各卡空白格解释成完整显存节省量。计算前AllGather、按策略重分片；激活、梯度、优化器和通信缓冲另计。 |
| `assets/images/fig-31.png` | 并行切开不同维度，对应不同协作形式 | 数据并行保留模型副本；张量并行示例为列切分权重/输出；流水线按连续层切分，前传激活、反传激活梯度；上下文并行仍需跨片段KV信息。不是加速比承诺。 |
| `assets/images/fig-33.png` | 训练恢复需要完整逻辑状态，而非只有权重 | 包括参数/分片布局、优化器、进度、随机、数据位置和运行身份。暂存不等于落盘，文件存在不等于已验证可恢复。改变规模或版本时另行验证。 |
| `assets/images/fig-34.png` | 训练工作负载应按数据来源、计算结构及额外系统成本比较 | LoRA/QLoRA不等于只剩适配器内存；在线蒸馏包括教师路径；DPO与在线RL区别在是否需要当轮生成等结构，具体算法变体以正文为准。 |
| `assets/images/fig-36.png` | 软硬件生态应逐层比较，而非只看峰值 | 层次包括模型、框架编译、内核库、通信运行、硬件系统。NVIDIA/AMD/Apple/Intel/TPU入口仅为例子，不表明功能等价、完整支持或性能排名。 |
