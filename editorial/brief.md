# 统一编写约定

面向有编程兴趣、具少量 Python 经验的中文读者。正文以因果解释、具体案例和可操作观察为核心，避免辞典罗列、AI 自问自答和营销腔。全书主线：一次训练迭代→硬件→单卡训练→编译→算子→性能→集群→工作负载。以小 Transformer、算子优化、集群扩展三个案例贯穿。

每章写约 1800—2800 个汉字（代码、引用不计），必要时更长；不能用提纲替代正文。解释首次术语，章节互相可独立阅读；代码少而完整，标明可运行/教学伪代码。重要推导有数值例子，明确假设。包含适合本章的教学图解计划，但不要写占位图片链接。主编稍后添加实际生成图。章末参考列出官方文档/原论文，正文邻近用 [1] 等标注。

资料核验至 2026-10-25。必须联网核实易变 API 与现代技术，优先官方文档/原论文；可用搜索工具通过 ALL_TOOLS 发现。不要虚构测试结果或硬件。引用他人性能必须讲条件，未经实测不得声称实测。新技术标明稳定/实验及硬件约束。区分 Ampere/Hopper/Blackwell 与消费/数据中心架构，不按品牌名假设功能。AMD wavefront 大小依架构；不要全写64。全书使用算子(operator)、内核(kernel)、显存、分块(tile)、矩阵计算单元；Tensor Core 是特定厂商名称。

各代理只写分配章节、自己的 references/research-XX.md 与 examples/XX-*。不修改共享 book.json、README、图文件和 Git，不创建 HTML，不直接生成 PDF。可把建议图放 research 文件，写明具体教学目的。完成后报告文件、参考与未实测限制。
